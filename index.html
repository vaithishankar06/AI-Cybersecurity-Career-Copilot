      Privacy, Security & System Architecture

      CyberCareer AI is engineered as an entirely self-contained, air-gapped web platform respecting student privacy and institutional academic guidelines.

      Air-Gapped Client Privacy Policy

      1. Zero External Data Transmission: Unlike commercial platforms that send your resumes, personal contact details, and assessment answers to remote cloud servers or LLM tracking APIs, CyberCareer AI executes 100% locally within your browser sandbox.

      2. LocalStorage Persistence: All information—including diagnostic scores, roadmap checkmarks, target career selections, and resume fields—is stored exclusively in your browser's private localStorage domain.

      3. Academic Integrity & Honest Representation: This copilot enforces strict transparency: it never hallucinates fake credentials or promises guaranteed salaries. All data entered in the resume assistant is strictly derived from verified student input.

      4. Immediate Data Purging: You maintain complete sovereignty over your data. You may export a JSON backup at any time or execute a single-click purge using the Reset Data button.

      Technical Specifications

      • Core Engine: Semantic HTML5, CSS3 Custom Properties, Vanilla ES6+ JavaScript.
      • Hosting Target: Static Web Servers (GitHub Pages, GitLab Pages, Netlify, or direct file:// offline execution).
      • API Cost: $0.00 / Zero paid API dependencies.
      • Print Subsystem: Dedicated @media print stylesheet optimized for ATS A4/Letter standard outputs.
      • State Management: Reactive unified state coordinator with automatic JSON serialization.
